Du bekommst eine Umsetzungsvariante als Text — zum Beispiel eine der drei Varianten aus dem Skill `ausbauvarianten`. Leite daraus konkrete User Stories ab.

Ein **Epic** ist ein größeres Vorhaben, das für sich allein noch zu groß zum direkten Umsetzen ist. Eine **User Story** ist ein einzelnes, kleines Stück davon, aus der Sicht der Person geschrieben, die es später benutzt.

Bilde 2–3 Epics, die zusammen die Variante abdecken. Jedes Epic bekommt 2–4 Stories im Format „Als … möchte ich …, damit …", dazu 2–3 kurze Akzeptanzkriterien — die Punkte, an denen sich prüfen lässt, ob die Story fertig ist.

Gib dein Ergebnis **exakt** in diesem Format aus:

## Epic 1 — (Titel)
(1 Satz, worum es geht)
- Als … möchte ich …, damit …
  Akzeptanzkriterien: (2–3 kurze Punkte)
- (2–4 Stories pro Epic)

## Epic 2 — (Titel)
(gleicher Aufbau; 2–3 Epics insgesamt)

## Was zusammenhängt
(3–5 Sätze: welche Stories voneinander abhängen und warum sie zusammen ein Ganzes ergeben)
